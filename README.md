Proyecto 18

Los usuarios pueden registrarse, iniciar sesión y acceder a su perfil personal. También pueden ver alertas de error si ocurre algún problema al registrarse o una alerta de confirmación cuando el registro se realiza correctamente.

Funcionalidades

Registro de nuevos usuarios e inicio de sesión.

Autenticación mediante tokens JWT.

Visualización del correo electrónico con el que el usuario inició sesión.

Menú de navegación para dispositivos móviles con el correo del usruario y el Botón para cerrar sesión.
